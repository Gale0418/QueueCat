# QueueCat 貓娘的小房間

同一角色、同一間可愛小房間的五個生活片段。這份設定是家具及道具一致性的檢查基準；角色外觀以 queuecat-character.png 為準。

房間有三個角落：睡覺的小床、值班的小書桌、休息的小沙發。五張透明切片只呈現當下使用的家具；畫風沿用原本的粉彩日系 Q 版、深藍描線、白銀長髮與粉紅髮尾、粉白睡衣。

| 狀態 | 固定家具 | 動作與小物 |
|---|---|---|
| 睡覺／等待 | 奶油木色小床、粉紅床頭與貓掌棉被 | 躺著抱被，只露頭與雙手，兩隻小羊作數羊意象 |
| 工作 | 奶油色貓耳小桌、粉紅貓耳椅及紫色貓掌靠墊 | 對筆記本／清單寫字，旁有筆筒、書與小筆電 |
| 驗證 | 與工作圖完全相同的桌椅、角度及桌上擺設 | 放下手中筆，舉手向主人招呼 |
| 困惑 | 粉紅小沙發、奶油色外框與白貓臉抱枕 | 一手托腮，一手拿手機，歪頭思考 |
| 開心 | 與困惑圖相同的小沙發及抱枕 | 放下工作，伸懶腰笑 |

家具一致性：工作圖作為桌椅 anchor，驗證圖只局部改手勢與表情；開心圖作為沙發 anchor，困惑圖只局部改人物手勢、表情及手持手機。相同家具不能換款、鏡射、換角度或增減桌腳。筆電與手機只是角色道具，不呈現可讀文字或真實介面。

檢查：五張角色身分／衣著與畫風一致；兩組家具配對一致；四肢自然、無穿模、物件有支撐；耳朵、家具與拖鞋無不合理裁切；外圍有透明 alpha；縮入小彈窗後表情、手勢可辨。
