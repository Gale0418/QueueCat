# QueueCat 放大背景貓貓與三語介面

本輪依使用者圈圖調整角色尺寸、下載卡片透明度與圖示，並由 Antigravity／Gemini 創作英文、繁體中文、日文產品文案；保留既有排隊防重、Chrome 下載分工、靜態家具圖、快捷操作與本機資料界線。

- 桌面角色 430px、彈窗 270px，窄窗依空間縮放。角色放在下載卡片下方且不攔點擊；卡片底色為淺色 80%／深色 90%，文字與進度維持不透明。彈窗說明以逐行紙色襯底保持可讀，避免大塊底色遮臉。
- 淺色卡片採較深的次要文字與紫色；以背景圖片純黑／純白的保守疊色估算，最小文字對比為淺色 4.72:1、深色 4.88:1。沒有使用背景模糊或新增角色動畫。
- 新貓臉與資料夾 SVG 維持同一圓潤筆畫；工具列 16／32／48／128px PNG 使用粉色耳朵、腮紅與奶油白貓臉。
- 語言預設 `system`：依瀏覽器偏好順序選第一個支援的英文／中文／日文；中文家族呈現繁體中文，全部不支援時回退英文。設定可手動覆寫或切回跟隨瀏覽器，背景協調器負責保存與驗證；舊版本缺失或無效值正規化為 `system`。
- 三語涵蓋按鈕、狀態、提示、無障礙標籤、頁面標題、分享簡介、通知、工具列提示與已知舊事件／原因。Chrome 擴充功能 metadata 以英文回退；Chrome 自己的原生介面由 Chrome 管理。
- 翻譯只處理程式擁有的訊息。檔名、網址以 `data-raw` 保護；不翻譯輸入值、連結目標與未知網站原文。已知歷史訊息採精確或整段模板比對，動態資料保留原樣。英文數量使用 Gemini 提供的函式處理單複數。
- 切換語言直接更新文字節點，保留網址輸入、焦點與展開狀態；一般進度刷新不重建整個介面。背景通知每次取得該任務狀態的語言，避免沿用 UI 的舊語系。
