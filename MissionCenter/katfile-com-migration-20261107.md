# Katfile 來源遷移至 com（QC-T27）

- 日期：2026-11-07（台灣時間）。使用者要求新網址及既有佇列的 `.cloud`、`.co` 來源改為 `.com`，並保留下載狀態。
- 只轉換有效的 Katfile 檔案來源頁，包含 www 別名；保留檔案 ID、查詢參數及跨網域去重，其他網域與 CDN 交接網址不改寫。
- 已保存佇列載入時先持久化遷移結果，再更新快取；其餘欄位包括下載 ID、狀態與交接 action 原樣保留。儲存失敗時不快取，下次可重試。
- 未交接的舊工作頁可於背景恢復或前往工作分頁時遷移；只有目標網域與已存來源一致才導頁，避免其他來源的站方轉址循環。等待頁重新連線後的倒數由網站重新回報。
- 驗證：`npm.cmd test` 23 個測試檔、303 項通過；`npm.cmd run build` 通過型別檢查、建置、MV3 驗證及 ZIP 封裝。測試涵蓋兩個舊網域、九種狀態、儲存重試與冪等、背景恢復、blocked 分頁、下載中重啟及轉址循環保護。
- 限制：沒有重載使用者現用外掛、直接修改 Chrome storage 或啟動實站下載。使用者重載新版後才會套用保存的佇列遷移；實際站方下載流程仍待使用者確認。
